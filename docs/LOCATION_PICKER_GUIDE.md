# Location Picker User Guide

## Overview
The Location Picker allows users to select their delivery address location in three convenient ways.

## How to Use

### Method 1: Search for Location 🔍
1. Type the location name in the search bar at the top
   - Example: "Central Park, New York"
   - Example: "Connaught Place, Delhi"
   - Example: "MG Road, Bangalore"
2. Select from the dropdown suggestions
3. The map will automatically pan to that location
4. A marker will be placed at the selected location
5. The coordinates are automatically captured

**Best for:** When you know the exact name or address of the location

---

### Method 2: Use Current Location 📍
1. Click the "Use Current Location" button
2. Allow browser location permission when prompted
3. The map will automatically center on your current GPS location
4. A marker will be placed at your location
5. The coordinates are automatically captured

**Best for:** When you're at the delivery location right now

---

### Method 3: Click on Map 🗺️
1. Navigate the map by:
   - Dragging to pan
   - Scrolling to zoom in/out
   - Using zoom controls (+/-)
2. Click anywhere on the map to place a marker
3. The search bar will show the address of that location
4. The coordinates are automatically captured

**Best for:** When you want to visually select a specific spot

---

## Fine-Tuning Location

### Drag the Marker
- After placing a marker (by any method), you can drag it to adjust
- Click and hold the marker
- Drag it to the exact spot
- Release to set the new position
- The coordinates update automatically

---

## What Gets Saved

When you save an address, the following location data is stored:

```
✓ Latitude (e.g., 28.6139)
✓ Longitude (e.g., 77.2090)
✓ Address text (from search or reverse geocoding)
```

This data is used for:
- Showing the exact location when you view/edit the address
- Calculating delivery distance
- Optimizing delivery routes
- Showing your location to delivery partners

---

## Editing Saved Addresses

When you edit an existing address:
1. The map automatically loads with your saved location
2. The marker appears at the saved coordinates
3. The map centers on your location
4. You can update the location using any of the three methods above

---

## Tips & Tricks

### For Best Results:
- **Zoom in** before clicking on the map for precise placement
- **Use search** for well-known landmarks or addresses
- **Drag marker** for final adjustments
- **Check coordinates** displayed below the map to verify

### Search Tips:
- Include city name for better results: "Sector 29, Gurgaon"
- Use landmarks: "Near Metro Station"
- Be specific: "Tower A, DLF Cyber City"

### Troubleshooting:
- **Location permission denied?** Use search or click on map instead
- **Can't find location?** Try zooming out and searching for nearby landmark
- **Wrong location?** Simply click again or drag the marker
- **Map not loading?** Check internet connection and refresh page

---

## Privacy & Permissions

### Location Permission:
- Only requested when you click "Use Current Location"
- Optional - you can use search or map click instead
- Permission can be revoked in browser settings
- Location is only used for this feature

### Data Storage:
- Coordinates are stored with your address
- Used only for delivery purposes
- Not shared with third parties
- Can be updated or deleted anytime

---

## Country Restrictions

The search is currently restricted to India. To change this:
- Contact support to enable other countries
- Or manually click on map for international addresses

---

## Keyboard Shortcuts

When search bar is focused:
- `Enter` - Select first suggestion
- `↓` / `↑` - Navigate suggestions
- `Esc` - Close suggestions

---

## Mobile Usage

On mobile devices:
- **Pinch** to zoom in/out
- **Tap** to place marker
- **Tap and hold** marker to drag
- Search bar is fully responsive
- "Use Current Location" works with phone GPS

---

## Support
